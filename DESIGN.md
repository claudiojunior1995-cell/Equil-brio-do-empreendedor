## 📋 O que encontrar no Figma

- 🎮 Protótipos do jogo
- 🖼️ Wireframes e layouts
- 🎨 Paleta de cores
- 📝 Tipografia
- 🧩 Componentes reutilizáveis
- 📱 Design responsivo (desktop, tablet, mobile)
- 🔄 Fluxos de usuário

## 💡 Dicas de Uso

### Para Designers
- Explore os frames e componentes principais
- Use as cores e tipografia estabelecidas
- Reutilize componentes existentes

### Para Desenvolvedores
- Use como referência visual durante o desenvolvimento
- Respeite as dimensões e espaçamento definidos
- Implemente os componentes conforme o design

### Para o Time
- Deixe comentários no Figma para feedback
- Mantenha sincronizado com mudanças de requisitos
- Documente novas versões de design

## 📋 Checklist de Desenvolvimento

- [ ] Layout responsivo implementado
- [ ] Cores e tipografia aplicadas
- [ ] Componentes reutilizáveis criados
- [ ] Testes de acessibilidade
- [ ] Revisão de design com o time
